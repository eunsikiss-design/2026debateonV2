# User-guide flow illustrations

Five original illustrations generated for the five cards in “앱의 전체 흐름”. Generated with the built-in image tool on 2026-09-25, then converted to WebP without cropping. They contain no student information, textbook scans, readable UI text, or logos. The Korean step text remains HTML so it is accessible and editable.

Shared art direction: tactile paper-cut / soft 3D editorial vignette, dark navy #142638, cyan #75dce6 and warm amber #d7a969, centered horizontal 3:2 composition, no writing or logos.

| File | Meaning |

| login.webp | Personal sign-in, roster verification and consent |
| topic.webp | Social-studies unit, debate and essay topic, concepts |
| activity.webp | Basic writing, essay writing and speech |
